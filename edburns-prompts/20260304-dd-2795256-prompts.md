```
* Find the shortest path for cargo transportation with Azure Open AI services
```

The code in `cargotracker-liberty-aks-azd` this feature is implemented in at least these two source files, maybe more:

./src/main/java/org/eclipse/pathfinder/api/GraphTraversalService.java
./src/main/java/org/eclipse/pathfinder/api/ShortestPathAiImpl.java

The feature is designed to only take effect if the `AZURE_OPENAI_KEY` environment variable is defined in the computer that is running the JVM that runs Liberty.

The deployment time configuration of this feature is defined in `charts/cargotracker-liberty-aks/templates/openlibertyapplication.yaml`.
